# 데이터 구성과 출처

## 공개 저장소에 포함한 데이터

| 파일 | 내용 | 출처 |
| --- | --- | --- |
| `backend/data/order_cases_cafe_200.json` | 카페 주문 의도 해석용 200건 | 프로젝트에서 직접 구성 |
| `backend/data/menu_cafe.json` | 시범 카페의 메뉴·조건·옵션 DB | 프로젝트에서 직접 구성 |
| `backend/data/eval_cases.json` | 주문 해석 점검에 사용하는 사례 | 프로젝트에서 직접 구성 |

`order_cases_cafe_200.json`에는 단순 주문, 옵션, 복수 주문, 정정 발화, 재질문이 필요한 표현, 비주문 발화를 함께 담았다. 이는 **AI Hub 원본 주문 데이터가 아니라** 서비스 목적에 맞춰 설계한 텍스트 사례다.

## AI Hub 활용

경상도 방언 표현의 학습·검토에는 AI Hub의 다음 데이터셋을 활용했다.

- [한국어 방언 발화(경상도)](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=119)
- AI Hub 경상도 발화 관련 데이터셋(프로젝트 학습 환경에서 별도 수집)

원천 음성·전사 파일은 용량과 AI Hub 이용약관을 고려하여 이 저장소에 포함하지 않았다. 해당 데이터는 AI Hub에서 직접 내려받아 각 데이터셋의 이용 조건을 확인한 뒤 사용해야 한다.

## 제외한 항목

- Kanana-2 3B 기반 모델 본체
- QLoRA 어댑터, 학습 체크포인트, 캐시
